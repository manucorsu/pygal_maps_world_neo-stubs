# pygal_maps_world_neo-stubs
This package contains PEP 561 type stubs for [pygal_maps_world_neo](https://github.com/manucorsu/pygal_maps_world_neo), my active fork of [pygal_maps_world](https://github.com/Kozea/pygal_maps_world).

They are intended to be used alongside [pygal-stubs](https://github.com/manucorsu/pygal-stubs) which has been added as a dependency of this package.

For more information, including the contribution guide, see the [pygal-stubs](https://github.com/manucorsu/pygal-stubs) repository.

To install, simply `pip install pygal_maps_world_neo-stubs` (or however you normally install a package).
